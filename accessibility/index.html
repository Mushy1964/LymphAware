Accessibility

Designed to be clear and accessible.

LymphAware ID is designed so that information can be accessed and understood as easily as possible by the people who use the service.

Last reviewed: 15 September 2026.

Accessibility from the beginning

Accessibility is considered throughout the LymphAware ID public website, Patient Portal and QR-linked patient profile.

The aim is to provide a service that is straightforward to navigate, easy to read and practical for people with different abilities, needs and levels of confidence with technology.

Accessibility is part of how LymphAware ID is designed and will continue to be reviewed as the service is tested and improved.

Simple and understandable

LymphAware ID uses clear language, consistent layouts and straightforward navigation.

Information is presented to help people find what they need without unnecessary complexity.

What the service supports

Accessibility considerations are built into the current LymphAware ID website and Patient Portal and remain part of ongoing testing.

Readable content

Text, headings and spacing are structured to make information easier to read and understand across different screen sizes.

Clear navigation

Pages use predictable navigation, meaningful headings and consistent layouts so people can find information more easily.

Good contrast

Colours and text are selected to provide useful contrast while remaining consistent with the LymphAware ID green and blue identity.

Keyboard use

Interactive parts of the service are intended to be usable without requiring a mouse wherever practical.

Assistive technology

Semantic headings, labels and alternative text are used to support screen readers and other assistive technologies where appropriate.

Responsive design

LymphAware ID is designed to work clearly on mobile phones, tablets and larger screens.

The QR-linked patient profile

Accessibility is particularly important when someone scans a LymphAware ID card.

The patient profile is designed so important information can be understood quickly on a mobile phone without complicated navigation or unnecessary detail.

Accessibility testing

LymphAware ID continues to review the website, Patient Portal and QR-linked profile during the invitation-only trial.

Practical testing across different devices, browsers and ways of using the service helps identify barriers that need improvement.

A formal independent accessibility audit has not yet been completed, so we do not currently claim a specific WCAG conformance level. Feedback from trial participants will help inform further testing before wider launch.

If something is difficult to use

Some accessibility barriers only become clear through real use.

Please use the Contact page if you experience an accessibility difficulty, need help using LymphAware ID or would like information in another reasonable format.

When reporting a problem, it is helpful to tell us which page or feature you were using and, if known, the device, browser or assistive technology involved.

Continuous improvement

Accessibility is treated as an ongoing responsibility rather than a one-off exercise.

Feedback from patients and other users will help identify and prioritise improvements as LymphAware ID grows.

Easy to find. Easy to read. Easy to understand.

LymphAware ID should remain simple and accessible because people may need to use it at moments when clear communication matters most.
